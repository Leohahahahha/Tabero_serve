# Repository working notes

When a new data, training, evaluation, deployment, sensor, control, or environment problem is investigated in this repository, update `docs/tabero_interview_incident_log.md` in the same task.

Each entry must include the problem name, diagnosis date, status, symptom, evidence, root cause or explicitly labeled hypotheses, fix, verification scope, and a concise interview explanation. Update the overview table as well. Do not present correlation as a proven cause, and distinguish implemented fixes from training, shadow, or real-robot validation that has not occurred.
